# Задача: скринсейвер «Двоичное время» для macOS

## Цель
Сделать нативный скринсейвер для macOS, который показывает текущие дату и время в двоичном виде строго по дизайну и спецификации из этого пакета.

## Входные материалы
| Файл | Что это |
|---|---|
| `SPEC.md` | Поведение и внешний вид, чек-лист приёмки (§9), принятые решения (§10) |
| `MACOS.md` | Технологии, обходы ошибок ScreenSaver.framework, соответствие API, структура проекта |
| `design/tokens.json` | Дизайн-система v1.0, единственный источник визуальных значений |
| `data/i18n.json` | Все тексты на 6 языках и правила письменностей |
| `data/celestial-catalog.json` | Справочник космических объектов для режима VPN |
| `reference/screenshots/` | Эталонные экраны: языки, темы, ультраширокий, портретный, узкий |
| `prototype/` | Работающий веб-прототип для сверки поведения (открыть `prototype/index.html`) |

## Объём v1.0
1. **Отображение:** год, месяц, день (группа «дата») и часы, минуты, секунды (группа «время») в двоичном виде, плюс десятичные значения и полная запись внизу. Сотые доли секунды убраны решением заказчика 03.11.2026 (SPEC §10.4).
2. **Формат времени:** 12 или 24 часа.
3. **Календари:** григорианский, исламский (Умм аль-Кура), еврейский, буддийский. Режим «авто»: сначала календарь из настроек macOS, затем часовой пояс, по умолчанию григорианский.
4. **Языки:** en, ru, he, ar, bo, ja. Для he и ar интерфейс зеркальный (RTL), для ar и bo — национальные цифры. По умолчанию язык системы.
5. **Местоположение:** город и страна по часовому поясу; если не определено — «Место не определено».
6. **VPN:** локальная проверка основного сетевого интерфейса. При VPN показывается случайный космический объект, смена каждые 20 с.
7. **Темы:** тёмная и светлая (инверсия), форма бита — круг или квадрат.
8. **Экран:** полностью адаптивный — любые размеры и пропорции, несколько мониторов.
9. **Настройки** в окне «Параметры» скринсейвера.
10. **Отладочное приложение (DebugHost)** с окном, меняющим размер, и кнопками-переключателями.

## Не входит в v1.0
- Windows, Linux, App Store.
- CoreLocation и точные координаты.
- Календари, которых нет в списке (в том числе персидский).
- Перевод тибетских названий космических объектов (используется английский).
- Онлайн-проверка VPN через IPLocate.io — этап 5, по отдельному подтверждению.
- Intel Mac и macOS старше 26 Tahoe — решение заказчика 09.11.2026 (SPEC §10.5): только Apple Silicon, без виртуальных машин для проверки старых систем.

## Этапы
| # | Результат | Готово, когда |
|---|---|---|
| 1 | Swift-пакет `Core` без AppKit: модель битов, календари (включая порядковый номер еврейского месяца), локализация (цифры, метки направления письма), часовой пояс → страна (`zone1970.tab`), локальный детектор VPN, загрузка токенов и JSON | Юнит-тесты зелёные: значения битов, крайние случаи (12 ч, 0/99 сотых, високосный еврейский год, смена года), все 6 языков |
| 2 | DebugHost и `ClockScene` на Core Animation | Внешний вид совпадает с `reference/screenshots/` для всех 11 случаев; изменение размера окна без мерцания |
| 3 | `.saver`: жизненный цикл с обходами из MACOS.md §2, окно параметров, несколько мониторов | Чек-лист MACOS.md §5 (кроме подписи); 20 циклов «запуск–выход» без накопления процессов |
| 4 | Шрифты в бандле, сборка arm64, скрипт подписи, нотаризации и сборки `.dmg`, README по установке | Устанавливается двойным щелчком на чистой Tahoe 26 и новее (проверяют тестировщики пре-релиза) |
| 5 (опция) | Онлайн-проверка VPN (IPLocate.io), выключена по умолчанию, ключ API задаёт пользователь | SPEC §4.4: кэш 10 мин, тайм-аут 3 с, откат на локальную проверку |

## Критерии приёмки
`SPEC.md` §9 и `MACOS.md` §5 — все пункты.

## Что нужно от заказчика
- Учётная запись Apple Developer (Developer ID) для подписи и нотаризации — на этапе 4.
- Проверка носителями языка текстов на he, ar, bo; до неё строки считаются черновыми.
- Сверка координат в `celestial-catalog.json` по SIMBAD и USGS Gazetteer.

## Как работать
Сначала прочитать `CLAUDE.md`, затем предложить план и структуру репозитория и дождаться подтверждения. После каждого этапа — короткий отчёт: что сделано, что проверено, отклонения от спецификации.
