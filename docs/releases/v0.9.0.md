# Binary Time 0.9.0 (beta, not signed)

The first public build, for testers. Version 1.0.0, signed with a Developer ID and notarized by Apple,
follows in December. Your settings carry over to it.

Requires macOS 26 Tahoe or later on a Mac with Apple silicon.

## This build is not signed

macOS blocks software that Apple has not checked. To install this beta, use one of the two ways below.

**With System Settings**

1. Open `BinaryTime-0.9.0-unsigned.dmg` and double-click **Binary Time.saver**.
2. macOS says that it cannot open the file. Click **Done**.
3. Open **System Settings › Privacy & Security** and scroll down to **Security**. Next to the message about
   Binary Time, click **Open Anyway** and enter your password.
4. Double-click **Binary Time.saver** again and choose to install it for you only or for all users.

**With Terminal**

Before you open the disk image, remove the quarantine flag that the browser added to it:

```bash
xattr -d com.apple.quarantine ~/Downloads/BinaryTime-0.9.0-unsigned.dmg
```

Then open the disk image and double-click **Binary Time.saver**.

After the install, select **Binary Time** in **Wallpaper › Screen Saver**. **Options…** sets the language,
calendar, theme and the rest.

Check the download against `BinaryTime-0.9.0-unsigned.dmg.sha256`:

```bash
shasum -a 256 -c BinaryTime-0.9.0-unsigned.dmg.sha256
```

## What to test

- The Hebrew, Arabic and Tibetan texts are drafts. If you read one of these languages, tell us what is
  wrong: the date line, the readout labels and the Options sheet.
- Macs with two or more displays.
- Memory and CPU after the screen saver has run for an hour or longer.
- Update: install a newer build over this one. Uninstall: Control-click **Binary Time** in the screen saver
  list and choose **Delete**.

Report problems in [Issues](https://github.com/amaklakov-droid/binary-time-screensaver/issues). Give the
macOS version, the Mac model and the settings in Options.

## По-русски

Первая публичная сборка, для тестировщиков. Подписанная и нотаризованная версия 1.0.0 выйдет в декабре,
настройки перейдут в неё.

Сборка не подписана, поэтому macOS её блокирует. Откройте dmg и дважды щёлкните **Binary Time.saver**, нажмите
«Готово». Затем в **Системных настройках › Конфиденциальность и безопасность** в разделе «Безопасность»
нажмите **«Всё равно открыть»**, введите пароль и снова дважды щёлкните **Binary Time.saver**.

Другой способ: до открытия dmg выполните в Терминале
`xattr -d com.apple.quarantine ~/Downloads/BinaryTime-0.9.0-unsigned.dmg`.

Особенно нужны отзывы носителей иврита, арабского и тибетского и тех, у кого несколько мониторов. Пишите в [Issues](https://github.com/amaklakov-droid/binary-time-screensaver/issues).
